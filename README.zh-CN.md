# Project Memory（项目记忆）

AI 助手每次新会话都从零开始。上个月的决定、踩过的坑、定下的边界，常常要重新讲一遍。Project Memory 把这些历史归档到项目本地，等模型下次需要时自己想起来。

## 它做什么

装好以后不用管它。后台在做三件事：

1. **记**。Codex 会话即将被压缩时，一个 hook 往队列里写一条"这段历史待整理"，马上返回，不占你会话的时间。
2. **整理**。worker 把转录切成有界页面，让模型提炼跨会话还值得记住的东西——做过什么决定、修过什么 bug、为什么这么做。每条都锚定到原始对话里的确切证据，存进项目自己的 `.memory-palace/`。
3. **想**。新会话里，问题要是依赖过往事实，模型会自己调 `memory_recall` 查出来接着干，而不是反问你"之前是不是做过"。

整条就那么长：历史自动归档，模型真会去读。

支持 macOS / Linux / Windows（Codex 的 hooks 与 MCP 机制三平台一致；只有 INSTALL.zh-CN.md 第 5 节的 launchd 常驻是 macOS 专属）。

## 自带模型，花小钱办大事

写入和读取都走你自己配的模型端点，不碰 Codex 或 Claude Code 的订阅额度。抽取这活对模型要求不高：会跟指令、会答中文、支持强制工具调用就够。按量计费的 flash 档模型，每个会话也就几次调用。四个环境变量怎么配写在了 INSTALL.zh-CN.md「端点与模型要求」里，`scripts/setup_env.py` 会引导填写并跑连通性测试。

## 一个项目，一套记忆，两个 agent 互通

Codex 和 Claude Code 读写的是同一个项目库：一条队列、一个数据库、一个 worker、一个召回工具。Codex 会话里记下的决定，切到 Claude Code 问得到，反过来也一样。不用在两边各养一份记忆；中途换 agent 什么都不会丢——记忆跟着项目走，不跟着工具走。（接入配置见 INSTALL.zh-CN.md「Claude Code 集成」。）

## 刻意保持简单

每项目一个 SQLite 库（八张表：`records`、`evidence`、`review_items`、`session_cursor`、`model_usage`、`audit_events`、`window_commit_markers`、`extraction_jobs`），一条队列，一个 worker，一个 MCP 工具。没有服务、没有分布式、没有要扩容的东西。转录是权威，记忆是派生层，删掉也能从转录重建。做记忆这活，简单就是可靠：全部家当装得进一个库，每条记忆都能指回转录里的一行。

## 适合谁

常年在同一个项目里跨会话干活的人用得着；受够了每次给 AI 补背景的人也用得着。要是你在意结论有出处——所有记忆锚定原始对话，可溯源、可删除、可重建——它同样合适。

## 怎么用

**安装**——复制下面这段（右侧有复制按钮）直接粘贴给你的 agent（Codex、Claude Code 或任意编程 agent），它会读安装指南并动手：

```
你正在从这个仓库安装 Project Memory 系统。请按以下要求执行：

1. 把本仓库克隆到合适位置并 cd 进入。
2. 完整阅读 INSTALL.md（想看中文版就读 INSTALL.zh-CN.md），并逐节执行：探测本机并确定安装形态（0.5 节）、安装依赖、验证导入、注册 Codex 集成；若检测到 Claude Code 还要注册 CC 兼容层（3.5 节）；用 scripts/setup_env.py 配置模型服务环境变量（只需填 URL 和 Key）并跑它的连通性测试。
3. 任何向本仓库以外写入的步骤（hooks.json、config.toml、settings.json、.claude.json、shell rc 文件、launchd）或消耗模型配额的步骤（连通性测试、6.5 节的历史会话回填），先把你将要做的展示给我，等我确认后再执行——回填前要把扫描统计结果也给我看。
4. 全部完成后运行验收清单（「验收清单」节），并把每一项结果报告给我。有失败的项，先按故障排查表（第 8 节）修复再汇报。
```

想手动安装的话直接按 `INSTALL.md` 操作。

**日常**：没有要跑的，没有要查的。

**想主动查**：正常问就行，比如"我之前在这个项目里对 X 是怎么做的？"——它自己会查记忆。

## 它不做什么

它提炼的是跨会话仍然有用的事实，不是手头任务的总结，也不是对你对话的评价。它不往外送任何数据：转录只在本地读，库在项目目录里，唯一的外联是你配的模型端点。证据不足的条目不进正式记录，先进审查队列等人确认。记忆引用原文的位置（证据 ID + 行号），不复制原文。

## 数据在哪，怎么清理

转录（原始证据）在 Codex 的会话目录，系统只读。记忆库在每个项目的 `.memory-palace/`——一个 SQLite 库加冻结的捕获副本。想清空某个项目的记忆，删掉它的 `.memory-palace/` 就行，转录不受影响。

## 快速验证已装上

```bash
codex mcp list   # memory_palace_recall 应显示 connected
```

3 分钟端到端验证（含模型调用）见 INSTALL.zh-CN.md「验收清单」。
